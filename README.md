# EasAI

Progetto Nuxt 4 + Storyblok con la stessa base di Gambazzi, Plissé e Borgo Rota
(moduli `gothamstoryblok`, `gothamform`, SCSS con `mw()`, componenti in `app/storyblok/`).

```bash
cp .env.example .env   # compilare le variabili
pnpm install
pnpm dev
```

Il layout in `base-html/` è il riferimento HTML da convertire in componenti Storyblok.
